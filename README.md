# OGC API – Processes Building Blocks

OGC API – Processes as [OGC Building Blocks](https://ogcincubator.github.io/bblocks-docs/):
schemas, OpenAPI components, requirements classes and specification text for
Part 1: Core (1.0 and 2.0 draft) and Part 2: Deploy, Replace, Undeploy (draft),
from which the standards documents are generated.

This repository merges three former GeoLabs repositories into a single register,
with their full Git history:

| Former repository | Content now in this repository |
| --- | --- |
| [GeoLabs/bblocks-ogcapi-processes](https://github.com/GeoLabs/bblocks-ogcapi-processes) | Part 1 API components (schemas, parameters, responses, paths), `scripts/` |
| [GeoLabs/bblock-ogcapi-processes-part2](https://github.com/GeoLabs/bblock-ogcapi-processes-part2) | Part 2 API components (OGC Application Package, execution units, CWL encoding) |
| [GeoLabs/ogcapi-processes-standard-as-bblocks](https://github.com/GeoLabs/ogcapi-processes-standard-as-bblocks) | Clauses, requirements classes and annexes; `standards.yaml`; `standard/` |

*API blocks* are the schemas and OpenAPI components (`api`, `schemas/`, `parameters/`,
`responses/`, `paths/`, `operations/`). *Document blocks* are the `clauses/`,
`requirements/` and `annexes/` that make up the standards documents.

Part 2 depends on Part 1 **version 1.0** (`part1.v1`), not on the 2.0 draft.
Part 2 is a draft and has not been adopted by OGC.

## Standards documents

[standards.yaml](standards.yaml) defines three documents, generated by the
[bblocks-specgen](https://github.com/ogcincubator/bblocks-specgen) build plugin declared in
[bblocks-config.yaml](bblocks-config.yaml):

| Id | Document | Source blocks |
| --- | --- | --- |
| `part1` | OGC API – Processes – Part 1: Core 2.0 (18-062r3, draft) | `ogc.api.processes.part1.v2.*` |
| `part1-v1` | OGC API – Processes – Part 1: Core 1.0 (18-062r2) | `ogc.api.processes.part1.v1.*` |
| `part2` | OGC API – Processes – Part 2: Deploy, Replace, Undeploy (20-044, draft) | `ogc.api.processes.part2.v1.*` |

The generated documents are written to `build/standards/`. The tracked
[standard/](standard/) directory holds earlier generated documents.

## Build and view locally

Requires Docker.

```sh
./build.sh   # validate and build the register into build-local/
./view.sh    # open the viewer at http://localhost:9090
```

`build.sh` runs `bblocks-postprocess` through
[scripts/build_official_sources.py](scripts/build_official_sources.py), which only
adapts the YAML reading of the bare CQL2 `=` scalar. Set `BBP_IMAGE_TAG` to pin a
postprocessor image. The build installs and runs the specgen plugin: review the
plugin permission prompt.

## Publication

On every push to `main`, [process-bblocks.yml](.github/workflows/process-bblocks.yml)
validates the blocks, generates the documents, commits `build/` and publishes to
GitHub Pages. Pull requests are checked read-only by
[pr-check.yml](.github/workflows/pr-check.yml).

Once published, the register is available at
<https://jfarduino.github.io/ogcapi-processes-bblocks/build/register.json>.

SPARQL upload is disabled in [bblocks-config.yaml](bblocks-config.yaml) until the
`sparql_username` and `sparql_password` secrets are configured for this repository.

## Part 1 source scripts

[scripts/](scripts/) embeds and audits the official OGC Part 1 schema and OpenAPI
definitions in `_sources/part1`. They only process the API blocks; document blocks
are skipped. Offline tests run in CI through
[python-scripts.yml](.github/workflows/python-scripts.yml):

```sh
python -m pip install -r requirements-dev.txt
python scripts/run_unit_tests.py
```

See [scripts/README.md](scripts/README.md) for the integration tests against the
official sources.
