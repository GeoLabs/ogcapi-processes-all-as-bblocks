# OGC API – Processes Building Blocks

Building Blocks for OGC API – Processes Part 1: Core (version 1.0, OGC 18-062r2,
and version 2.0 draft, OGC 18-062r3) and Part 2: Deploy, Replace, Undeploy
(OGC 20-044, draft), together with the requirements, clauses and annexes from
which the standards documents are generated.


This repository brings together, in a single register, the technical and
normative Building Blocks of OGC API – Processes that were previously spread
across three repositories:

- GeoLabs/bblocks-ogcapi-processes: Part 1 schemas, parameters, responses and paths
- GeoLabs/bblock-ogcapi-processes-part2: Part 2 schemas and responses (OGC Application
  Package, execution units, CWL encoding)
- GeoLabs/ogcapi-processes-standard-as-bblocks: requirements classes, clauses and
  annexes, used to generate the standards documents with bblocks-specgen

Part 2 is still a draft standard and has not been adopted by OGC.
